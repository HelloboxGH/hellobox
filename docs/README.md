# HelloBox docs

HelloBox is a shared inbox for teams that already send email through a provider like Amazon
SES, Postmark, Mailgun or Resend. It reads and answers your mail through your own provider
account.

## Run it yourself

[Self-hosting](self-hosting/README.md) takes you from an empty server to HelloBox at your own
address, step by step. You don't need to have run a server before.

- [Before you start](self-hosting/before-you-start.md): what you need, and the words you'll
  meet.
- [Install HelloBox](self-hosting/install.md), once the server is ready.
- [All settings](../.env.example), each one explained.
- [Troubleshooting](self-hosting/troubleshooting.md).

Rather not run a server? Use the hosted version at [hellobox.app](https://hellobox.app).
